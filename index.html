Merton Retirement Withdrawal Strategy

This tool implements Robert Merton's retirement withdrawal strategy using stochastic modeling of asset returns (geometric Brownian motion). It separates essential and discretionary spending and provides a dynamic withdrawal strategy that adapts to market conditions.

Theory Behind Merton's Retirement Withdrawal Strategy

Stochastic Modeling of Asset Returns

The implementation uses geometric Brownian motion to model asset returns, which is the same mathematical framework used by Robert Merton in his groundbreaking work on option pricing and portfolio theory.

Key Components of the Model

  • Geometric Brownian Motion (GBM): Models stock prices as following a log-normal distribution, capturing both drift (expected return) and volatility.
  • Present Value Annuity Factor (PVAF): Used to calculate the appropriate withdrawal rate based on portfolio value, expected returns, and remaining time horizon.
  • Essential vs. Discretionary Spending: Separates necessary expenses from flexible spending, ensuring basic needs are met first.
  • Guardrails: Limits on how much withdrawals can change each year to provide income stability.
  • Portfolio Construction: Models combined stock/bond portfolio with correlation effects on overall risk and return.

Mathematical Background

The stochastic differential equation (SDE) for geometric Brownian motion is:

dS = μS dt + σS dW

Where:

  • S is the asset price
  • μ is the drift (expected return)
  • σ is the volatility
  • dW is a Wiener process (Brownian motion)

The solution to this SDE gives the price at time t as:

S(t) = S(0) * exp((μ - σ²/2)t + σW(t))

This produces more realistic market simulations than simple deterministic models, accounting for the actual statistical properties of market returns.

Advantages Over Traditional Withdrawal Methods

Compared to traditional approaches like the 4% rule, Merton's approach offers several benefits:

  1. Adapts to market conditions: Recalculates annually based on actual portfolio performance rather than assuming constant returns.
  2. Risk-aware: Explicitly models market volatility and correlation between asset classes.
  3. Prioritizes essential spending: Ensures basic needs are covered before allocating to discretionary expenses.
  4. Time-horizon optimization: Adjusts withdrawals based on remaining life expectancy rather than using a fixed rate.
  5. Realistic market modeling: Uses stochastic processes that better represent actual market behavior.

The implementation shown here combines theoretical rigor with practical considerations like withdrawal stability guardrails to create a robust retirement income strategy.

JavaScript Implementation

This is the JavaScript code used to implement Merton's retirement withdrawal strategy with stochastic modeling:

/**
 * JavaScript implementation of the Merton Retirement Strategy
 * using geometric Brownian motion for stochastic modeling
 */

class MertonStrategy {
    constructor(params) {
        // Store inputs
        this.age = params.age;
        this.life_expectancy = params.life_expectancy;
        this.years = this.life_expectancy - this.age;
        this.portfolio_value = params.portfolio_value;
        this.essential_income = params.essential_income * 12;
        this.guaranteed_income = params.guaranteed_income * 12;
        this.income_gap = Math.max(0, this.essential_income - this.guaranteed_income);
        
        // Portfolio allocation
        this.stock_allocation = params.stock_allocation / 100;
        this.bond_allocation = params.bond_allocation / 100;
        
        // Market parameters
        this.stock_return = params.stock_return / 100;
        this.stock_volatility = params.stock_volatility / 100;
        this.bond_return = params.bond_return / 100;
        this.bond_volatility = params.bond_volatility / 100;
        this.correlation = params.correlation;
        this.inflation = params.inflation / 100;
        
        // Strategy parameters
        this.max_change = params.max_change / 100;
        this.num_simulations = params.simulations;
        
        // Calculate portfolio parameters
        this.calcPortfolioParams();
    }
    
    // Calculate the portfolio's expected return and volatility
    calcPortfolioParams() {
        // Expected return (arithmetic)
        this.portfolio_return = (this.stock_allocation * this.stock_return + 
                                this.bond_allocation * this.bond_return);
        
        // Portfolio volatility using correlation formula
        this.portfolio_volatility = Math.sqrt(
            this.stock_allocation**2 * this.stock_volatility**2 + 
            this.bond_allocation**2 * this.bond_volatility**2 + 
            2 * this.stock_allocation * this.bond_allocation * 
            this.correlation * this.stock_volatility * this.bond_volatility
        );
        
        // Real return (accounting for inflation)
        this.real_return = (1 + this.portfolio_return) / (1 + this.inflation) - 1;
        
        // For GBM: adjust drift for volatility effect
        this.geo_return = this.portfolio_return - 0.5 * this.portfolio_volatility**2;
    }
    
    // Calculate Present Value Annuity Factor
    calcPVAF(rate, years) {
        if (rate === 0) {
            return years;
        }
        return (1 - (1 / (1 + rate)**years)) / rate;
    }
    
    // Calculate initial withdrawal using Merton's approach
    initialWithdrawal() {
        const pvaf = this.calcPVAF(this.real_return, this.years);
        return this.portfolio_value / pvaf;
    }
    
    // Run a single simulation of the retirement period
    runSingleSimulation() {
        const portfolio_values = [this.portfolio_value];
        const withdrawals = [];
        const monthly_withdrawals = [];
        const essential_coverage = [];
        
        // Calculate initial withdrawal
        const initial_withdrawal = this.initialWithdrawal();
        let prev_withdrawal = initial_withdrawal;
        
        for (let year = 0; year < this.years; year++) {
            // Calculate this year's withdrawal
            let current_withdrawal;
            if (year === 0) {
                current_withdrawal = initial_withdrawal;
            } else {
                // Recalculate based on current portfolio and remaining years
                const remaining_years = this.years - year;
                const pvaf = this.calcPVAF(this.real_return, remaining_years);
                const new_withdrawal = portfolio_values[portfolio_values.length - 1] / pvaf;
                
                // Apply guardrails to limit annual changes
                const floor = prev_withdrawal * (1 - this.max_change);
                const ceiling = prev_withdrawal * (1 + this.max_change);
                current_withdrawal = Math.min(ceiling, Math.max(floor, new_withdrawal));
            }
            
            // Store withdrawal info
            withdrawals.push(current_withdrawal);
            monthly_withdrawals.push(current_withdrawal / 12);
            
            // Calculate essential coverage - using guaranteed income first, then portfolio withdrawals
            let coverage;
            if (this.income_gap > 0) {
                coverage = Math.min(current_withdrawal / this.income_gap, 1) * 100;
            } else {
                coverage = 100;
            }
            essential_coverage.push(coverage);
            
            // Simulate market returns using geometric Brownian motion
            if (portfolio_values[portfolio_values.length - 1] <= current_withdrawal) {
                // Portfolio depleted
                portfolio_values.push(0);
            } else {
                // Random return with log-normal distribution (GBM)
                const remaining = portfolio_values[portfolio_values.length - 1] - current_withdrawal;
                
                // Generate a standard normal random variable using Box-Muller transform
                const u1 = Math.random();
                const u2 = Math.random();
                const z = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
                
                // Apply to GBM formula
                const random_return = Math.exp(this.geo_return + this.portfolio_volatility * z);
                const new_value = remaining * random_return;
                portfolio_values.push(Math.max(0, new_value));
            }
            
            // Update for next iteration
            prev_withdrawal = current_withdrawal;
        }
        
        return {
            portfolio_values: portfolio_values,
            withdrawals: withdrawals,
            monthly_withdrawals: monthly_withdrawals,
            essential_coverage: essential_coverage,
            initial_withdrawal: initial_withdrawal,
            initial_monthly: initial_withdrawal / 12,
            initial_discretionary: Math.max(0, (initial_withdrawal / 12) - Math.max(0, (this.essential_income - this.guaranteed_income)/12))
        };
    }
    
    // Run multiple simulations and process results
    runAllSimulations() {
        const all_results = [];
        
        // Run the specified number of simulations
        for (let i = 0; i < this.num_simulations; i++) {
            all_results.push(this.runSingleSimulation());
        }
        
        // Extract initial values from first simulation
        const initial_withdrawal = all_results[0].initial_withdrawal;
        const initial_monthly = all_results[0].initial_monthly;
        const initial_discretionary = all_results[0].initial_discretionary;
        
        // Extract data for analysis
        const portfolio_values_by_year = [];
        for (let year = 0; year < all_results[0].portfolio_values.length; year++) {
            const year_values = all_results.map(result => result.portfolio_values[year]);
            portfolio_values_by_year.push(year_values);
        }
        
        const withdrawal_values_by_year = [];
        for (let year = 0; year < all_results[0].withdrawals.length; year++) {
            const year_values = all_results.map(result => result.withdrawals[year]);
            withdrawal_values_by_year.push(year_values);
        }
        
        // Calculate success rate as percentage of simulations where essential coverage 
        // remained at 100% or above throughout retirement
        const success_count = all_results.filter(result => {
            // Check if essential coverage was maintained at 100% throughout retirement
            return result.essential_coverage.every(coverage => coverage >= 100);
        }).length;
        const success_rate = (success_count / this.num_simulations) * 100;
        
        // Calculate percentiles for final portfolio value
        const final_values = all_results.map(result => 
            result.portfolio_values[result.portfolio_values.length - 1]
        );
        const median_end = this.percentile(final_values, 50);
        const percentile_10 = this.percentile(final_values, 10);
        
        // Calculate median withdrawals at year 10 and 20
        let median_withdrawal_10 = 0;
        if (withdrawal_values_by_year.length > 9) {  // Year 10
            median_withdrawal_10 = this.percentile(withdrawal_values_by_year[9], 50);
        }
        
        let median_withdrawal_20 = 0;
        if (withdrawal_values_by_year.length > 19) {  // Year 20
            median_withdrawal_20 = this.percentile(withdrawal_values_by_year[19], 50);
        }
        
        // Generate detailed table data
        const detail_table = [];
        for (let year = 0; year < all_results[0].withdrawals.length; year++) {
            const age = this.age + year + 1;
            const portfolio = this.percentile(all_results.map(result => result.portfolio_values[year+1]), 50);
            const withdrawal = this.percentile(all_results.map(result => result.withdrawals[year]), 50);
            const monthly = this.percentile(all_results.map(result => result.monthly_withdrawals[year]), 50);
            const coverage = this.percentile(all_results.map(result => result.essential_coverage[year]), 50);
            
            detail_table.push({
                year: year + 1,
                age: age,
                portfolio: portfolio,
                withdrawal: withdrawal,
                monthly: monthly,
                coverage: coverage
            });
        }
        
        // Generate percentile data for charts
        const percentile_data = {
            years: [...Array(all_results[0].portfolio_values.length).keys()],
            portfolio: {
                p1: portfolio_values_by_year.map(values => this.percentile(values, 1)),
                p5: portfolio_values_by_year.map(values => this.percentile(values, 5)),
                p10: portfolio_values_by_year.map(values => this.percentile(values, 10)),
                p25: portfolio_values_by_year.map(values => this.percentile(values, 25)),
                p50: portfolio_values_by_year.map(values => this.percentile(values, 50)),
                p75: portfolio_values_by_year.map(values => this.percentile(values, 75)),
                p90: portfolio_values_by_year.map(values => this.percentile(values, 90)),
                p95: portfolio_values_by_year.map(values => this.percentile(values, 95)),
                p99: portfolio_values_by_year.map(values => this.percentile(values, 99))
            },
            withdrawal: {
                p1: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 1))],
                p5: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 5))],
                p10: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 10))],
                p25: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 25))],
                p50: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 50))],
                p75: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 75))],
                p90: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 90))],
                p95: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 95))],
                p99: [0, ...withdrawal_values_by_year.map(values => this.percentile(values, 99))]
            }
        };
        
        return {
            initial_withdrawal: initial_withdrawal,
            initial_monthly: initial_monthly,
            initial_discretionary: initial_discretionary,
            income_gap: this.income_gap,
            success_rate: success_rate,
            median_end: median_end,
            percentile_10: percentile_10,
            median_withdrawal_10: median_withdrawal_10,
            median_withdrawal_20: median_withdrawal_20,
            detail_table: detail_table,
            percentile_data: percentile_data
        };
    }
    
    // Helper method to calculate percentiles
    percentile(values, p) {
        // Make a copy and sort the values
        const sorted = [...values].sort((a, b) => a - b);
        const k = (sorted.length - 1) * p / 100;
        const f = Math.floor(k);
        const c = Math.ceil(k);
        
        // If k is an integer, return the corresponding value
        if (f === c) {
            return sorted[k];
        }
        
        // Otherwise, interpolate between the two nearest values
        const d0 = sorted[f] * (c - k);
        const d1 = sorted[c] * (k - f);
        return d0 + d1;
    }
}
